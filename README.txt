============================================================
  三角洲行动 · 烽火地带「玩法风格推荐器」 v2.3（多工程模块化版）
  使用与修改说明
============================================================

一、总体结构（一个解决方案，8 个工程）
------------------------------------------------------------
  用 VS2026 打开 DeltaForceAdvisor.sln，解决方案分为两组：

  01_Modules_Lib（7 个静态库工程，各自独立，方便逐个查看与整合）
    DFA_Weapons   枪械模块：枪械清单（大类 + 二级分类）、类别评分、大类别名解析
    DFA_CustomWeapons 自定义枪械模块：扫描 txt/csv 文件夹，载入玩家私人枪械
    DFA_Operators 干员模块：干员清单（代号/本名/兵种/技能）、兵种评分
    DFA_Maps      地图模块：地图 + 难度清单、评分、每图开放难度表、核心物资区文案
    DFA_Economy   资金模块：哈夫币分档、分档评分、固定队友评分
    DFA_Styles    玩法模块：五种玩法的名称、标语与完整档案
    DFA_Engine    推荐引擎：汇总各模块评分、选优、强制兜底规则
                    （依赖枪械/自定义枪械/干员/地图/资金 5 个模块）

  02_MainApp
    DFA_Main      整合入口（控制台应用）：菜单输入 + 输出建议
                    （链接全部 7 个模块库，编译后即完整程序）

  依赖方向：主程序 → 引擎 → 枪械/自定义枪械/干员/地图/资金（玩法模块被主程序直接使用）。
  每个工程均为「空项目」式结构：不生成向导代码，头文件 + 源文件全手写，
  便于你按模块打开、阅读、微调。

二、怎么运行 / 编译
------------------------------------------------------------
  1. VS2026 打开 DeltaForceAdvisor.sln
  2. 配置选 Release | x64
  3. 「生成 → 生成解决方案」（按依赖自动先编译各模块库，再链接主程序）
  4. 产物在  bin\x64\Release\DFA_Main.exe（根目录另有一份 DeltaForceAdvisor.exe
     副本），双击即可运行（/MT 静态链接，x64 Windows 直接运行，无需 VC++ 运行库）

  命令行编译（VS2026 开发者命令行）：
    msbuild DeltaForceAdvisor.sln /p:Configuration=Release /p:Platform=x64

三、怎么微调 / 增加数据（按模块找「配置区」）
------------------------------------------------------------
  每个模块的 .cpp 文件顶部都有醒目的「配置区」注释，改完重新编译即可：

  1. 加枪械        → DFA_Weapons\dfa_weapons.cpp 的 kWeapons 数组加一行
                    （格式：{ "枪名", "二级分类标签", 大类 }）
  2. 调枪械评分    → 同文件 kWeaponScore 对应行（列顺序 = 跑刀/鼠鼠/正常玩/微交战/全装猛攻）
  3. 加干员        → DFA_Operators\dfa_operators.cpp 的 kOperators 数组加一行
                    （格式：{ "代号", "本名", 兵种, "核心技能摘要", "适配提示" }）
  4. 调兵种评分    → 同文件 kRoleScore 对应行
  5. 加地图        → DFA_Maps\dfa_maps.cpp 的 kMaps 加一行 + kMapScore 加一行
                      + kAllowedDiffs 加一行（-1 结尾，写明该图开放的难度）
  6. 加难度        → 同文件 kDiffs 加一行 + kDiffScore 加一行
                      + 在相关地图的 kAllowedDiffs 行里加入该难度编号
  7. 调资金分档    → DFA_Economy\dfa_economy.cpp 的 kWealthTiers 阈值
  8. 改玩法文案    → DFA_Styles\dfa_styles.cpp 的 kGuides
  9. 加玩法        → dfa_common.h 的 DfaStyle 追加 + 各模块评分表各加一列
                      + DFA_Styles 追加名称/标语/档案
 10. 加推荐规则    → DFA_Engine\dfa_engine.cpp 的 DFA_E_ForceRule
 11. 加私人枪械    → 不用改代码：在 DFA_Main.exe 同级建「自定义枪械」文件夹，
                      放入 .txt/.csv，每行「枪名 | 大类 | 跑刀,鼠鼠,正常玩,微交战,全装猛攻」，
                      评分可整段省略（用大类默认分）；程序启动自动载入，菜单从第 70 项起。
                      换目录：--weapon-dir <目录> 或环境变量 DFA_WEAPON_DIR；
                      格式详见 自定义枪械\格式说明.md

  模块接口（供你自己写代码时调用）都声明在各模块的 .h 头文件里，
  参数与返回值均有注释说明。

四、数据口径说明
------------------------------------------------------------
  依据游戏内设定与玩家社区共识整理（NGA / B 站攻略 / 抖音百科 / 官方公告 /
  云马克 yunmaku.com 干员资料页等），非官方数据，仅供参考。主要口径：
  - 枪械：69 个内置选项，9 大类（突击步枪/冲锋枪/狙击步枪/射手步枪/霰弹枪/
          轻机枪/手枪/特殊武器/通用）+ 游戏内二级分类标签（gunRifle/gunSMG/
          gunSniper/gunMP/gunShotgun/gunLMG/gunPistol/special）
  - 自定义枪械：运行时从「自定义枪械」文件夹读取，上限 256 条，不占内置编号
  - 干员：18 名，4 兵种 —— 支援（旅人/蝶/蛊/蜂医）、工程（液氮/比特/深蓝/
          乌鲁鲁/牧羊人）、侦察（回响/银翼/骇爪/露娜）、突击（疾风/无名/
          威龙/红狼/野火），技能与适配提示来自云马克资料页（2026-09-24 调整后）
  - 地图：6 张 —— 零号大坝 / 长弓溪谷 / 巴克什 / 航天基地 / AZ3 / 潮汐监狱
  - 难度：5 档 —— 普通 / 机密 / 绝密 / 永夜 / 超临界，按地图限定开放：
        零号大坝：普通 / 机密 / 永夜（无绝密）
        长弓溪谷：普通 / 机密（无绝密）
        巴克什、航天基地：机密起步 → 机密 / 绝密
        AZ3：普通 / 绝密 / 超临界
        潮汐监狱：仅绝密
  - 核心物资区：输出时按所选地图展示（数据在 DFA_Maps 的 kLootZones）；
        AZ3 超临界会额外提示随机泄漏点与辐射扩散
  - 起装成本参考：机密正常玩约 40~60w；微交战 60~120w；全装猛攻 100~250w+
  - 资金分档阈值（万）：100 / 500 / 1500，可在 DFA_Economy 修改
