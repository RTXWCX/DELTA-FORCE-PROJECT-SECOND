# 三角洲行动 · 烽火地带 玩法风格推荐器（DFA Advisor）

> 基于游戏内设定与玩家社区攻略整理的非官方 **离线 C++ 桌面工具**。
> 输入你的枪械 / 干员 / 地图 / 难度 / 哈夫币存量 / 固定队友情况，自动给出五档玩法建议：
> **跑刀 · 当鼠鼠 · 正常玩 · 微交战 · 全装猛攻**（含评分、判断依据、玩法档案、风险提示）。

- 纯 C++ 控制台程序，不读取游戏进程、不挂钩、无任何自动操作，与游戏零交互。
- 多工程模块化设计（7 个 VS 工程），数据集中在各模块「配置区」，方便微调与扩展。
- VS2026（MSVC v145 / C++17），Release x64 静态链接（/MT），单 exe 即可分发。

---

## 功能与输入输出

```
请依次输入以下 6 项信息：
【1/6】擅长 / 精通的枪械        —— 69 个选项，8 大类（含游戏内二级分类）
【2/6】主玩 / 精通的干员        —— 17 名干员，4 兵种（支援 / 工程 / 侦察 / 突击）
【3/6】常去的地图                —— 6 张地图（零号大坝 / 长弓溪谷 / 巴克什 / 航天基地 / AZ3 / 潮汐监狱）
【4/6】常玩的难度                —— 按地图限定开放（普通 / 机密 / 绝密 / 永夜）
【5/6】当前哈夫币存量（万）
【6/6】是否有固定组队队友

输出：推荐玩法 + 各玩法评分 + 判断依据（枪械 / 干员 / 地图 / 难度 / 资金 / 队友）+ 完整玩法档案 + 风险提示
```

**地图与难度开放规则（已内置校验）**：长弓溪谷无绝密；零号大坝有永夜、无绝密；AZ3 仅普通 + 绝密；航天基地、巴克什机密起步；潮汐监狱仅绝密。

**评分模型**：`总分 = 枪械类别分 + 干员兵种分 + 地图分 + 难度分 + 资金分档分 + 队友分`；强制兜底：`绝密 + 资金 < 100 万 → 强制跑刀`。

## 工程结构（7 个工程，VS2026 解决方案）

```
DFA_ModularProjects
├── Common\dfa_common.h            公共定义（玩法枚举、档案结构）
├── DFA_Weapons\                   枪械模块：69 把枪械 8 大类 + 类别评分
├── DFA_Operators\                 干员模块：17 名干员 4 兵种 + 兵种评分
├── DFA_Maps\                      地图模块：6 图 4 难度 + 每图难度白名单
├── DFA_Economy\                   资金模块：哈夫币分档 + 固定队友评分
├── DFA_Styles\                    玩法模块：五种玩法的完整档案文案
├── DFA_Engine\                    推荐引擎：汇总评分、选优、强制兜底规则
├── DFA_Main\                      主程序：菜单交互与输出（入口）
└── DeltaForceAdvisor.sln          解决方案
```

## 编译与运行

**要求**：Windows x64 + Visual Studio 2026（含 C++ 桌面开发工作负载）

1. 用 VS2026 打开 `DeltaForceAdvisor.sln`
2. 顶部配置选择 **Release | x64**
3. `生成 → 重新生成解决方案`
4. 运行 `DFA_Main\bin\x64\Release\DFA_Main.exe`（或解决方案根目录副本 `DeltaForceAdvisor.exe`）

> exe 为 /MT 全静态链接，仅依赖系统 KERNEL32.dll，可直接拷贝到其他 Windows x64 电脑运行，无需安装 VC++ 运行库。

## 如何扩展（改数据不用改逻辑）

| 想改什么 | 改哪里 |
|---|---|
| 加枪械 | `DFA_Weapons\dfa_weapons.cpp` 的 `kWeapons` 数组加一行 |
| 调枪械评分 | 同文件 `kWeaponScore` 对应行 |
| 加干员 | `DFA_Operators\dfa_operators.cpp` 的 `kOperators` 数组加一行 |
| 调兵种评分 | 同文件 `kRoleScore` 对应行 |
| 加地图 / 难度 | `DFA_Maps\dfa_maps.cpp` 的 `kMaps` / `kDiffs` + `kAllowedDiffs` 白名单 |
| 调资金分档 | `DFA_Economy\dfa_economy.cpp` 的 `kWealthTiers` |
| 改玩法文案 | `DFA_Styles\dfa_styles.cpp` 的 `kGuides` |
| 加玩法 / 推荐规则 | `dfa_common.h` 的 `DfaStyle` + 各评分表 + `DFA_Engine\dfa_engine.cpp` 的 `DFA_E_ForceRule` |

改完：`Ctrl+S` 保存 → 重新生成解决方案 → 运行新 exe。
