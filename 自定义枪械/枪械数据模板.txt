# ============================================================================
#  私人枪械数据模板（DFA Advisor）
# ----------------------------------------------------------------------------
#  用法：复制本文件为「我的枪械.txt」，把下面的示例行去掉行首 # 后改成自己的数据。
#        程序启动时会自动扫描本文件夹所有 .txt / .csv。
#
#  每行一条枪，格式：
#      枪名 | 大类 | 跑刀,鼠鼠,正常玩,微交战,全装猛攻
#    - 分隔符 | , 全角，/、 均可；行首 # ; // 为注释。
#    - 评分写 5 个 -99~99 的整数；省略则套用该大类默认分。
#    - 大类可写：突击步枪/冲锋枪/狙击步枪/射手步枪/霰弹枪/轻机枪/手枪/特殊武器/通用
#      （也接受 AR、SMG、DMR、gunRifle 等别名）。
#    - 枪名不能与内置枪械或已有自定义枪重名（英文不区分大小写）。
#    - 最多 256 条；单文件不超过 4MB。
#    - 编码自动识别：UTF-8 / UTF-16 / 记事本 ANSI(GBK) 都行。
#
#  详细说明见同目录「格式说明.md」。
# ============================================================================

# ---- 示例（去掉行首 # 即可生效）------------------------------------------
# 我的M4A1 | 突击步枪 | 1,1,4,5,5
# 测试狙   | 狙击步枪
# 私人冲锋枪，冲锋枪，2,3,3,4,4
