# 自定义枪械数据 —— 格式说明

本文件夹就是「私人枪械数据」的默认扫描目录：

```
DeltaForceAdvisor.exe
自定义枪械\
    枪械数据模板.txt        ← 本程序只会读取这里的 .txt / .csv
    格式说明.md              ← 说明文件，程序不会读取
```

把任意多个 `.txt`（或 `.csv`）放进本文件夹，重新启动程序即可在枪械菜单末尾
看到【自定义枪械】分组，编号接在内置枪械之后。文件按**文件名升序**读取，
同一文件内按**行序**排列。

---

## 一、每行一条枪

```
枪名 | 大类 | 跑刀,鼠鼠,正常玩,微交战,全装猛攻
```

- **分隔符**：`|`、`,`、全角 `，`、`、` 都可以混用。
- **注释**：行首为 `#`、`;`、`//`（也支持全角 `＃`、`；`）的行会被忽略。
- **空行**：自动忽略。
- **枪名**：任意中文 / 英文，不能与内置枪械或已载入的自定义枪重名
  （英文不区分大小写）。重名条目会被跳过，并在启动时提示。
- **大类**：见下表；写中文名或别名都行，英文不区分大小写。
- **评分**：5 个整数，范围 `-99 ~ 99`，含义与内置评分表一致
  （正数 = 该玩法更契合，负数 = 不推荐）。**省略评分时**自动套用该大类的默认分。
- **最多 256 条**，单文件不超过 4MB。

## 二、可用大类

| 中文名 | 可用别名 | 对应内置默认分（跑刀/鼠鼠/正常玩/微交战/全装猛攻） |
| --- | --- | --- |
| 突击步枪 | 突击、步枪、AR、gunRifle | 0, 0, 3, 4, 4 |
| 冲锋枪 | 冲锋、SMG、gunSMG | 1, 2, 2, 3, 3 |
| 狙击步枪 | 狙击、狙、sniper、gunSniper | 0, 1, 2, 4, 1 |
| 射手步枪 | 射手、DMR、marksman、gunMP | 0, 1, 2, 3, 1 |
| 霰弹枪 | 霰弹、喷子、shotgun、gunShotgun | 2, 2, 1, 1, 1 |
| 轻机枪 | 机枪、LMG、gunLMG | 0, 0, 2, 3, 2 |
| 手枪 | pistol、handgun、gunPistol | 3, 3, -1, -2, -3 |
| 特殊武器 | 特殊、弓、special、bow | 2, 3, 1, 1, -2 |
| 通用 | 其他、其它、generic、other | 0, 0, 1, 1, 1 |

> 内置「其他 / 通用」那把枪的名字是 `其他 / 通用`，自定义枪不要用同名。

## 三、示例

```
# 只写大类，评分走默认
我的 M4A1 改 | 突击步枪

# 写满 5 个评分，覆盖默认分
测试狙 | 狙击步枪 | 0,1,2,5,1

# 用逗号、全角分隔符都可以
私人冲锋枪，冲锋枪，2,3,3,4,4
```

## 四、编码

程序会自动识别：

- UTF-8（带不带 BOM 都行）
- UTF-16 LE / BE（带 BOM）
- 中文 Windows 记事本默认的 ANSI / GBK

所以直接用记事本另存即可，不需要特意转编码。若某行有问题，启动时会打印
形如 `枪械数据.txt:3 大类无法识别：XXX` 的提示，并跳过该行（不影响其他行）。

## 五、换一个目录

默认读取 exe 同级的 `自定义枪械` 文件夹。也可以：

1. 启动参数：`DeltaForceAdvisor.exe --weapon-dir "D:\我的枪械数据"`
2. 环境变量：`set DFA_WEAPON_DIR=D:\我的枪械数据`

优先级：启动参数 > 环境变量 > 默认文件夹。
